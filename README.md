# EIC Command DApp

Claim and admin tooling for EIC campaigns. Built with Next.js and Ethers.

## Quick start

1) Copy env template
   - cp .env.local.example .env.local
2) Install
   - npm install
3) Run
   - npm run dev

## Scripts

- npm run dev
- npm run build
- npm run start

## Environment

See .env.local.example for required variables.

## Deployment

Deploy with a Node 18+ runtime. Configure server-side secrets via environment variables.
